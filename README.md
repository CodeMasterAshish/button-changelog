# Changelog Timeline

A simple and clean changelog timeline built using only HTML and CSS. This project displays updates in a vertical timeline format with dates, milestone indicators, and descriptions.

## Preview

The timeline showcases:

- A centered page heading
- A short description section
- Vertical timeline layout
- Circular milestone markers
- Update dates and descriptions
- Call-to-action button

## Features

- Pure HTML and CSS
- No JavaScript required
- Clean and minimal UI
- Beginner-friendly project
- Responsive-friendly structure
- Uses CSS Grid and Pseudo Elements

## Technologies Used

- HTML5
- CSS3
